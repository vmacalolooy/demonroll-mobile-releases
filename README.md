# DemonRoll for Android

Downloads for the Android version of DemonRoll.

**[Download the latest DemonRoll.apk](https://github.com/vmacalolooy/demonroll-mobile-releases/releases/latest/download/DemonRoll.apk)**

Needs Android 11 or newer.

## Installing

1. Open the download link on your phone and download `DemonRoll.apk`.
2. Tap the downloaded file. If Android asks, allow your browser to install apps.
3. Open DemonRoll and follow the Guide tab. It walks you through turning DemonRoll on in Accessibility settings.

If Android says "Restricted setting" when you switch it on: open Settings, Apps, DemonRoll, tap the three-dot menu at the top right, choose "Allow restricted settings", then try again.

## Updating

Download the newer `DemonRoll.apk` from the same link and install it over the old one. Your profiles and history are kept.
